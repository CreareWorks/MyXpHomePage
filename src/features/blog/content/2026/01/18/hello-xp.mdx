## Windows XP風OS特有のこだわり(操作感)
- **ドラッグ＆ドロップ可能なウィンドウ**
- **スタートメニューの開閉**
- **画面右下の時計表示やアイコン表示**
- **フォントの見た目等の細かなデザイン**

<br/>
これらを実装し、訪れた人が少しでも懐かしさを感じながら楽しんでいただけるような体験になればと考えております。
<br/>
